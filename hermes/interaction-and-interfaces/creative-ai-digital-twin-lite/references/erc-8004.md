# ERC-8004 On-Chain Alignment — Reference

This reference supports the `creative-ai-digital-twin` and `creative-ai-digital-twin-lite` Hermes skills.

## Network

- **Chain:** Base (chain ID 8453)
- **RPC:** `BASE_RPC_URL`
- **Wallet:** `PRIVATE_KEY` (0x-prefixed, dedicated agent wallet)

## Contract Concept

ERC-8004 is a standard interface for registering a digital-twin alignment score. The exact contract address should be loaded from the Pinata/OpenClaw deployment configuration or the operator's `workspace/AGENTS.md`.

## Typical Function

```solidity
function registerAlignment(
  address creator,
  uint256 coherenceScore,
  uint256 roundsCompleted
) external returns (bytes32 alignmentId);
```

## Hermes Implementation Notes

1. Use `viem` or `ethers.js` to connect to `BASE_RPC_URL`.
2. Load the wallet from `PRIVATE_KEY`.
3. Ensure the wallet has enough Base ETH for gas (recommend keeping only the minimum needed).
4. Build the transaction with the current `coherenceScore` and `roundsCompleted`.
5. Send and wait for confirmation.
6. Log the transaction hash and return a BaseScan link:
   - `https://basescan.org/tx/{txHash}`

## Safety Rules

- Do not use the operator's personal wallet.
- Do not register unless `roundsCompleted >= 10` and `coherenceScore >= 100`.
- Always confirm with the operator before sending the transaction.
- Abort if `BASE_RPC_URL` or `PRIVATE_KEY` is missing or invalid.
